# 常见问题

## 启动与运行

**Q：双击 exe 没反应 / 弹一个空白窗口？**
A：先看 WebView2。Win10/11 一般自带；顶栏「环境自检」会逐项列出。个别系统 WebView2 不可用时程序会退回 Edge 应用模式，功能一样。也可在源码模式下看控制台报错。

**Q：杀软报毒？**
A：PyInstaller 打包的 exe 常被误报。程序不联网、不写系统目录、服务只监听 `127.0.0.1`。请自行判断是否加信任；发布说明里有 MD5 / SHA256 可核对。作者不提供签名二进制。

**Q：要不要装 Python / .NET / VC++？**
A：分发版 exe **都不用装**。源码运行才需要 Python 3.11+ 与 `requirements.txt` 里的依赖。

**Q：Linux / macOS 能用吗？**
A：暂不支持。依赖 WebView2、`winreg`、资源管理器 `/select,`、游戏目录里的 CNCMaps 渲染器。

## 地图与预览

**Q：地图没预览 / 显示 0x0？**
A：多半是文件头被塞了 UTF-16 BOM。用顶栏「环境自检」扫描，点「一键修复」；修前会自动备份。

**Q：修完头之后地图反而找不到了？**
A：文件结尾还挂着一行孤立的 `[`，客户端 INI 解析器读到它会抛异常。v2.2 起体检是**头 + 尾双向**，一次清理两头。如果用的是旧版，请先升到 v2.2 以上再修。

**Q：预览图是假的格子，不是真实地形？**
A：没找到 `Resources/RandomMapGenerator_RA2/Map Renderer/CNCMaps.Renderer.exe`，程序退回了纯格网底图。把渲染器放回游戏目录即可；其余功能不受影响。

**Q：删了地图，游戏里还显示？**
A：v1.4 起删除会同步清 `MPMaps*.ini` 的 `[MultiMaps]` 编号与注册段。若是手工在游戏外删的文件，用一次「归类 / 注册管理」刷新。

## 名称与筛选

**Q：勾「含字母 / 只有字母」，为什么结果里有纯中文地图？**
A：这是 v2.4 的默认口径问题，v2.4.1 已修：默认改成**按文件名（卡片标题）**。卡片标题是磁盘文件名，游戏大厅显示的是 INI `[Basic] Name`，629 张样本里 447 张两者不同。若你手动切到「按游戏名」，中文卡片仍可能命中 —— 此时卡片会标出「大厅名：xxx」，那就是判定依据；`No name` 这类占位名会自动回退到文件名。详见 [CHANGELOG 的 v2.4.1 条目](../CHANGELOG.md)。

**Q：为什么按文件名搜不到游戏里显示的那个名字？**
A：搜索框同时匹配文件名与内部名；想严格按大厅名找，把筛选依据切到「按游戏名」。

## 平台导入

**Q：平台导入扫出来 174 条，为什么只有 172 能导？**
A：2 个 `.ra2mp` 的地图主体是平台自有加密，标为「加密锁定」并拒绝写入 —— 不做破解、不伪造坏图。正确通道是在平台里开一局该图，平台会把明文落到游戏目录 `mp.dat` / `spawnmap.ini`，再扫描「平台解包缓存」导入。详见 [平台地图导入说明](平台地图导入说明.md)。

**Q：导入会不会改坏我的平台目录？**
A：不会。平台目录全程只读；写入只发生在你选的目标地图目录，且覆盖前自动备份。

**Q：同名地图怎么办？**
A：可选跳过 / 改名 / 覆盖。默认跳过最安全；覆盖前一定备份。

## AI

**Q：填了 Key 为什么还是不能用？**
A：① 点「获取模型」拉列表并**多选启用**；② 在「当前使用」里指定 `(连接, 模型)`；③ 密码框留空 = 沿用已保存的密钥（明文不回显是刻意设计）。

**Q：某个 Key 余额用完会中断任务吗？**
A：开启「自动兜底」后，402 / 429 / 超时 / 断网会自动切下一个可用模型，不会做一半停下。

**Q：我的 Key / 地图会被上传吗？**
A：地图文件不会。API Key 只存本地 `数据/ai_config.json`，配置接口只回 `hasKey` / `keyMasked`。但**启用 AI 时，你的提问与地图元数据会发给你自己配置的服务商**，介意就不要启用。

## 刷矿 / 编辑

**Q：刷的矿位置不对 / 渲染出黑洞？**
A：① 地图是菱形，`w=50` 时 `y=10` 行只有 `x=41..59` 有效，别往四角刷；② 不要直接改格子的 level（v2.4 起工具箱里已移除「抬高地形」）。

**Q：矿 / 宝石在某些 MOD 里不对？**
A：Overlay ID 是 **mod 相关**的，要从 `expandmdXX.mix` 的 `[OverlayTypes]` 明文读取（本地重聚环境矿 105~124、宝石 28~39）。CNCMaps 渲染器硬编码的 102~121 在该 mod 上全错。欢迎带实测数据提 Issue。

**Q：改坏了能回滚吗？**
A：所有写盘操作先备份，失败整体回滚；删除走回收站可还原。但仍建议操作前自己留一份地图目录副本。
