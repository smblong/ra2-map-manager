# 架构与技术说明

给想改代码或适配新环境的人。这里记的都是实际踩过的坑，不是理想设计。

## 分层

| 层 | 实现 |
| --- | --- |
| 窗口 | `pywebview` + WebView2（EdgeChromium 后端，`pythonnet` / `clr_loader`）；`native_win.py` 放 Windows 原生辅助 |
| 前端 | `web/index.html` 单页，原生 JS 无框架。两个 script 块：主块挂 `window.__app`，painter 块依赖 `__app` 并挂 `window.__pt`，整块 try/catch 落到 `window.__errs` |
| 服务 | `ra2map.py` 的 `ThreadingHTTPServer`，只监听 `127.0.0.1`；`/api/*` 路由集中在 `api_*` 方法 |
| 地图读写 | `mapio.py`（二进制段）、`ini_edit.py`（INI 保序）、`mapgen.py` / `mapedit.py`（生成与绘制）、`mapfog.py`（迷雾）、`modereg.py`（模式与注册） |
| 平台导入 | `platform_import.py`，纯只读扫描 + 显式导入 |
| AI | `ai_proxy.py`，OpenAI 兼容 `/models` 与 `/chat/completions` |

`web/index.html` 是 **LF**，`ra2map.py` 是 **CRLF**。批量替换脚本按 `\n` 拼串去匹配 CRLF 文件会全部失败 —— 处理前先探行尾。

## 地图格式要点

| 项 | 事实 |
| --- | --- |
| 文件类型 | `.map/.mpr/.yrm/.mms`，本质是 INI 文本；段名按 latin-1 写回 |
| 重名段 | 样本中 73 张图存在重名段（如 `[Virus]`），`parse_sections()` 必须返回**保序列表**而不是 dict |
| 清地瓦片 | tileset 0；`OverlayData` 值 0~11，真实矿区多为 8~11 |
| overlay 索引 | `Dx + 512 * Dy` |
| Waypoint | `Dx * 1000 + Dy` |
| 压缩 | `OverlayPack` / `OverlayDataPack` = LCW；`IsoMapPack5` = LZO，重打包时用 `'lit'` 纯字面量（CNCMaps 的 C# MiniLZO 移植版解不了匹配 token） |
| PreviewPack | 样本中 18 张异常，编辑器对这些图做只读保护 |
| 菱形 | `row_span(y, w)`；`w=50`、`y=10` 时有效 `x=41..59`。测试和刷格子要选中心区域 |
| 矿/宝石 ID | **mod 相关**。从 `expandmd01.mix` 明文 `[OverlayTypes]` 读；本地重聚环境矿 105~124（实用 112）、宝石 28~39（实用 30）。CNCMaps 渲染器硬编码 102~121 在此 mod 全错 |

## 两套名字

- 卡片显示**磁盘文件名**（`stem` / `fileStem`）
- 游戏大厅显示 INI `[Basic] Name`（`name`）

629 张样本里 **447 张不同**。大厅名常带 `WWW.RA2.CLUB` 广告后缀，也可能是 `No name` 之类占位串（实测 18 张）。所以名称特征筛选必须能切口径，且要对占位名做回退 —— 这就是 v2.4.1 的修复点。

| 筛选（629 张） | 按游戏名 | 按文件名 |
| --- | ---: | ---: |
| 含字母 | 591 | 183 |
| 只有字母 | 125 | 100 |
| 只有中文 | 22 | 411 |
| 含数字 | 482 | 96 |

## 名称筛选 API

```
GET /api/maps?nf=hasalpha&nf=hasdigit&nflogic=and&nfbase=file
```

- `nf` 可重复或逗号分隔，最多 8 个；`nflogic=and|or`
- `nfbase=name|file`；**不带参数时后端默认 `name`**（旧 API 兼容，不要改），前端默认 `file`
- `nf_value(m, nfbase)`：按 `name` 口径时，占位名回退到 `fileStem`
- 与 `only` / `q` / `folder` / `mode` 叠加
- 前端用 `MAPS_SEQ` 请求序号防异步竞态

## 平台导入 API

```
GET  /api/platform/scan?root=<平台目录>
GET  /api/platform/thumb?id=<条目 id>
POST /api/platform/import        { ids, target, conflict, backup }
```

`import_items()` 会再做一次 `_is_map_text(data)` 校验：加密主体或非法文本一律拒绝写入，避免把坏图塞进游戏目录。

## AI 配置结构

```
CONFIG_VERSION = 2
connections[] : { id, name, preset, baseUrl, key, models[], enabledModels[], timeout, enabled }
active        : { connId, model }
fallback      : bool
temperature   : float
```

- `(connId, model)` 才是实际调用项 —— 同一模型可以存在于不同连接
- `public_config()` 只回 `hasKey` / `keyMasked`，**永不回传明文**
- 旧单连接配置自动迁移
- 可重试状态：401 / 402 / 403 / 404 / 408 / 409 / 429 / 500 / 502 / 503 / 504 / 520~524，以及超时、连接失败

## 打包

`红警地图管理器.spec` 的 `hiddenimports` 必须包含所有本地模块与 WebView2 后端：

```
native_win, webview, webview.platforms.winforms, webview.platforms.edgechromium,
clr_loader, clr_loader.netfx, pythonnet,
ai_proxy, platform_import, trigger_defs,
ini_edit, mapio, mapgen, mapedit, overlay_catalog, modereg, mapfog
```

新增 Python 模块时**忘了加这里，源码能跑、EXE 里会缺模块**。版本资源在 `version_info.txt`（`filevers` / `FileVersion` / `ProductVersion` 三处）。

## 安全与写盘约定

1. 任何写盘先备份，失败整体回滚
2. 平台目录只读
3. AI 方案确认后才落盘
4. 明文 Key 不回显、不上传、不写日志
5. `/api/openfolder` 用 `['explorer', '/select,' + path]` **单参数**（拆两参数遇带空格路径会失效）

## 缓存与临时目录

`数据/` 下：`config.json`、`元数据缓存.json`、`预览缓存/`、`地形底图/`、`地图备份/`、`回收站/`、`临时/`、`运行日志.txt`、`ai_config.json`。全部由 `.gitignore` 排除。

UI 测试必须把 `DATA` / `CONFIG_PATH` / `META_CACHE_PATH` / `TRASH` / `TMP` / `BACKUP_DIR` 隔离到临时目录，否则会污染源码 `数据/ai_config.json`。
