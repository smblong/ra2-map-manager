## 1. 地图库

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 浏览 / 搜索 | 顶栏搜索框 | 按文件名与地图内部名匹配；左侧按目录 / 游戏模式双分类 |
| 预览筛选 | 侧栏 chip | 全部 / 缺预览 / 有预览 |
| 名称特征筛选 | 搜索栏后多选条 | 见第 2 节 |
| 批量勾选 | 卡片左上角 | 支持批量归类、批量取消迷雾、批量重绘预览、批量导出 |
| 右键归类 / 搬目录 | 卡片右键 | 可同时改游戏模式与所在目录，会同步 `MPMaps*.ini` 注册项 |
| 右键定位文件 | 卡片右键 | 「打开地图文件位置」，资源管理器打开并**选中**该文件 |
| 回收站还原 | 侧栏 | 删除走程序内回收站，可还原 |

> 预览图由游戏自带的 CNCMaps 渲染器生成，缓存在 `数据/预览缓存/`，可删、会重新渲染。

## 2. 名称特征筛选（v2.4.1）

- **多选**：含字母 / 含数字 / 含中文 / 只有字母 / 只有中文 / 不含字母 / 不含中文 等 12 种筛选码，可勾多个。
- **逻辑**：默认「同时满足」（AND），可切「满足任一」（OR）。「含字母 + 含数字」等价于原来的「字母+数字混合」。
- **依据**：默认**按文件名（卡片所见）**，可切「按游戏名（大厅显示）」。两者 629 张里 447 张不同。
- **占位名**：`No name`、空、`unnamed`、`未命名` 等不是真名字，按游戏名口径时自动回退到文件名。
- **可解释**：筛选激活时右侧写明依据；按游戏名口径时卡片下方多一行「大厅名：xxx」。

| 筛选（629 张实测） | 按游戏名 | 按文件名（默认） |
| --- | ---: | ---: |
| 含字母 | 591 | 183 |
| 只有字母 | 125 | 100 |
| 只有中文 | 22 | 411 |
| 含数字 | 482 | 96 |

## 3. 平台地图导入

顶栏「平台导入」→ 选平台根目录（默认自动探测）→ 扫描 → 勾选 → 选目标目录 → 导入。

- 只读扫描，平台目录不会被写入。
- 中文名从 GBK 索引还原，预览图按 hash 配对。
- 同名支持 **跳过 / 改名 / 覆盖**，覆盖前自动备份。
- 加密的 `.ra2mp` 标为「加密锁定」，拒绝导入（详见 [平台地图导入说明](平台地图导入说明.md)）。
- 默认目标 `Custom`；也可选游戏中已有的其它地图目录。

## 4. AI 助手配置 / AI 助手

**配置**（顶栏「AI 助手配置」）

| 项 | 说明 |
| --- | --- |
| 连接 | 可添加多条 OpenAI 兼容连接，同一模型也能配不同 `baseUrl` / Key / 超时 |
| 获取模型 | 填 Key 后点「获取模型」拉 `/models`，列表里**多选启用** |
| 当前使用 | 指定默认调用项；实际调用项是 `(连接 ID, 模型名)` 这一对 |
| 自动兜底 | 可关闭；开启时遇到余额不足 / 限流 / 超时自动切下一个可用模型 |
| 密钥 | 明文只存本地，前端密码框留空 = 沿用已保存的密钥 |

**助手**（顶栏「AI 助手」，各模块内的 `data-ai` 按钮）

- 可选模块：地图库 / 详情 / 编辑器 / 绘制 / 游戏模式 / 导入 / 平台导入 / 迷雾等，各模块有对应系统提示。
- 用中文描述需求，AI 先给**方案**，点「应用」才写盘；写前备份、失败整体回滚。

## 5. 统一编辑器（FA2 风格）

- 左工具箱：**矿石 / 宝石 / 清除 / 出生点**（没有「抬高地形」——直接改 level 会让渲染出黑洞）。
- 中画布：CNCMaps 输出的真实地形大图；按住**右键拖动**平移；拖动左右栏边框可调宽度。
- 右属性栏：中文参数名 + ⓘ 用法说明；点参数名可在地图上**高亮作用位置**。
- 触发动作：`[Actions]` 改成中文下拉，选完自动拼回原始数字串，也可切回直接写原文。

> 地图是菱形：`row_span(y, w)`，w=50 时 y=10 行有效 x 为 41..59。刷格子/测试要选**菱形中心区域**，别往四角刷。

## 6. 环境自检与坏字节修复

顶栏「环境自检」逐项核对：exe 形态、版本、WebView2、.NET、CNCMaps 渲染器、游戏目录。

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 大厅里没预览、大小 0x0、作者 Unknown | 文件头被塞 UTF-16 BOM（`FF FE`） | 一键修复，只去掉开头 4 字节 |
| 修完头之后整张图从列表消失 | 文件结尾还挂着一行孤立的 `[` | v2.2 起头尾双向体检，一次清理 |

修复前原文件备份到 `数据/地图备份/BOM修复-<时间>` 或 `坏字节修复-<时间>`。
