取消迷雾 / 全图可见 

  

    

    

      
      
      
      
    

    

      ⚠ 联机注意：「揭示全图」用的是地图触发器动作 16（Reveal all map），
      ModEnc 标注在多人对战里可能引起重连错误。单机、自建娱乐房、测试图建议开启；
      正式联机图可以只勾「免费雷达 + 关闭战争迷雾」这两个零风险项。

      改动前自动备份到 数据/地图备份/，随时可点「恢复迷雾」撤销。
    

    

  

  

    
    
    
    
  







  
导入其他平台地图 HT / RA2OL · MP.dat · .ra2mp · 解包缓存

  

    

      
      
      
    

    
点「扫描目录」开始；不会改动平台里的任何文件。

    

      
      
      
      
      
    

    

    

      导入到
      同名
      
    

    

    

      格式说明：平台地图库 MP.dat 里是明文标准 .map，可直接导入；
      .ra2mp 的地图主体是平台自有加密，官方明确无法从外部取出代码 —— 这类图会标为「加密」，
      请先在平台里打开/开一局该图，平台会把明文写到游戏目录的 mp.dat，再扫描一次从「平台解包缓存」导入。
      平台图可能依赖 Ares / Phobos 素材，导入到别的 MOD 后出现缺素材属正常现象。
